Panduan

ktp-kit membaca KTP di perangkat pengguna dan memberi hasilnya sekali, sebagai JSON. Formulir, aturan edit, dan penyimpanan tetap milik aplikasi Anda. Panduan ini dari pemasangan sampai data tiba di server.

Pasang

  1. Pasang paket: 
    npm install ktp-kit
  2. Salin model dan runtime (4,9 MB, sudah dikompres) ke folder yang dilayani web Anda: 
    npx ktp-kit assets public/ktp-kit
    Jalankan lagi setiap kali memperbarui ktp-kit. Folder ini yang nanti dipakai sebagai base.
  3. Kirim dua header ini di halaman yang memakai ktp-kit. Dengan header ini pembacaan memakai beberapa inti CPU dan sekitar 3 kali lebih cepat (2-4 detik di HP kelas menengah): 
    Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
    Akibatnya, skrip, gambar, dan iframe dari domain lain harus mengizinkan dimuat lintas origin. Tanpa header ini ktp-kit tetap jalan, hanya lebih lambat.

Pakai

Pilih satu cara. Semuanya memberi hasil yang sama.

HTML biasa (Laravel Blade, PHP, Django, Rails, Svelte...)

<script type="module">import "ktp-kit/element";</script>
<ktp-capture base="/ktp-kit/" lang="id"></ktp-capture>
<script>
  document.querySelector("ktp-capture").addEventListener("ktp-result", e => {
    console.log(e.detail);   // lihat "Isi hasil" di bawah
  });
</script>

Atribut: base (folder dari langkah 2), lang (id atau en), upload="false" untuk menyembunyikan tombol unggah foto. Event: ktp-result, ktp-state, ktp-error. Tampilan diatur lewat variabel CSS dan ::part(), lihat README.

React

npm install @ktp-kit/react

import { KtpCapture } from "@ktp-kit/react";
<KtpCapture base="/ktp-kit/" onResult={r => setKtp(r)} />

Vue

npm install @ktp-kit/vue

<KtpCapture base="/ktp-kit/" @result="r => ktp = r" />

Tanpa UI (tampilan sendiri)

import { useKtpCapture } from "@ktp-kit/react";   // sama di @ktp-kit/vue
const { videoRef, state, shoot, retake, readFile } = useKtpCapture({ base: "/ktp-kit/" });
// state.status: searching | adjust | hold | reading | done | error
// state.hint: kunci pesan (MESSAGES), state.corners: sudut kartu untuk digambar
// state.result: hasil saat status "done" (card berupa piksel, bukan Blob)

Node.js dan baris perintah

npx ktp-kit read foto/*.jpg          # satu baris JSON per foto
npx ktp-kit read foto/*.jpg --csv    # atau CSV

perlu_dicek

Kolom yang layak dicek ulang oleh pengguna, dengan alasan berupa kode. Kalimat untuk pengguna Anda yang menentukan.

KodeArtinya
nik_mismatchIsi kartu berbeda dengan yang tersandi di NIK (tanggal lahir, jenis kelamin). Salah satunya salah baca.
from_nikTulisan di kartu tidak terbaca, jadi nilainya diambil dari NIK. Biasanya benar, tapi bukan hasil baca kartu.
low_confidenceNama atau alamat: pembaca ragu pada setidaknya satu huruf, sering karena buram atau pantulan cahaya. Pada foto uji, tanda ini menangkap sekitar 3 dari 4 nama yang salah baca.

Contoh formulir

Taruh hanya kolom yang Anda butuhkan. Nama input sama dengan nama kolom hasil, jadi lima baris ini mengisinya. Kolom lain diabaikan.

<ktp-capture base="/ktp-kit/"></ktp-capture>
<form id="daftar">
  <input name="nik"> <input name="nama"> <input name="tanggal_lahir">
  <button>Daftar</button>
</form>
<script>
  let ktp = null;
  const form = document.getElementById("daftar");
  document.querySelector("ktp-capture").addEventListener("ktp-result", e => {
    ktp = e.detail;
    for (const [k, v] of Object.entries(ktp)) if (form.elements[k]) form.elements[k].value = v ?? "";
  });
</script>

Kolom yang tidak boleh diubah pengguna cukup diberi readonly. Untuk menandai kolom yang perlu dicek:

for (const [kolom, alasan] of Object.entries(ktp.perlu_dicek))
  form.elements[kolom]?.classList.add("perlu-dicek");

React

const [form, setForm] = useState({ nik: "", nama: "" });
<KtpCapture base="/ktp-kit/" onResult={r => setForm({ nik: r.nik ?? "", nama: r.nama ?? "" })} />
<input value={form.nik} onChange={e => setForm({ ...form, nik: e.target.value })} />

Kirim ke server

Kirim formulir seperti biasa. Foto KTP hanya ikut bila Anda memang perlu menyimpannya.

form.addEventListener("submit", async e => {
  e.preventDefault();
  const data = new FormData(form);
  data.append("ktp", ktp.card, "ktp.jpg");   // opsional
  await fetch("/daftar", { method: "POST", body: data });
});

Di server, perlakukan isinya sebagai masukan pengguna, karena pengguna bisa mengubah formulir. Cek ulang NIK dengan fungsi yang sama:

import { nikValid, nikConflicts } from "ktp-kit";

app.post("/daftar", upload.single("ktp"), (req, res) => {
  const { nik, tanggal_lahir, jenis_kelamin } = req.body;
  if (!nikValid(nik)) return res.status(400).json({ error: "NIK tidak valid" });
  const beda = nikConflicts({ nik, tanggal_lahir, jenis_kelamin });   // misalnya ["tanggal_lahir"]
  if (beda.length) return res.status(400).json({ error: "Tidak cocok dengan NIK", kolom: beda });
  // simpan
});

Butuh kepastian bahwa NIK benar-benar terdaftar? Itu perlu cek ke data Dukcapil lewat penyedia resmi. Panggil dari server Anda, hanya untuk pendaftaran yang memerlukannya.

Offline

Saat pertama dipakai, ktp-kit menyimpan model di perangkat (Cache API). Setelah itu pembacaan jalan tanpa internet selama halaman terbuka. Agar halaman juga bisa dimuat ulang tanpa internet, aplikasi Anda perlu service worker yang menyimpan halaman itu sendiri (HTML, skrip, gaya). Contoh singkatnya ada di apps/demo/sw.js.

Privasi

Foto dan isi KTP tidak meninggalkan perangkat sampai aplikasi Anda sendiri yang mengirimnya. Satu-satunya permintaan jaringan dari ktp-kit adalah unduhan modelnya. UU PDP meminta data yang dikumpulkan secukupnya, jadi kirim hanya kolom yang Anda butuhkan, dan jangan simpan foto KTP bila tidak wajib.

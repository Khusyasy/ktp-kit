Docs

ktp-kit membaca KTP langsung di device user, lalu memberi result dalam bentuk JSON. Form, validasi, dan penyimpanan tetap di app Anda. Docs ini membahas dari install sampai data masuk ke server.

Install

  1. Install package-nya: 
    npm install ktp-kit
  2. Copy model dan runtime (4,9 MB, sudah dikompres) ke folder public app Anda: 
    npx ktp-kit assets public/ktp-kit
    Jalankan ulang setiap update ktp-kit. Path folder ini nanti dipakai sebagai base.
  3. Tambahkan dua header ini di halaman yang memakai ktp-kit, supaya WebAssembly bisa pakai beberapa thread. Hasilnya sekitar 3x lebih cepat, 2-4 detik per KTP di HP mid-range: 
    Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
    Efek sampingnya, script, gambar, dan iframe dari domain lain harus mengizinkan cross-origin. Tanpa header ini ktp-kit tetap jalan, hanya lebih lambat.

Cara pakai

Pilih salah satu. Result-nya sama.

HTML (Laravel Blade, PHP, Django, Rails, Svelte...)

<script type="module">import "ktp-kit/element";</script>
<ktp-capture base="/ktp-kit/" lang="id"></ktp-capture>
<script>
  document.querySelector("ktp-capture").addEventListener("ktp-result", e => {
    console.log(e.detail);   // lihat bagian Result
  });
</script>

Attribute: base (path dari langkah 2), lang (id atau en), upload="false" untuk menyembunyikan tombol upload. Event: ktp-result, ktp-state, ktp-error. Styling lewat CSS variable dan ::part(), detailnya di README.

React

npm install @ktp-kit/react

import { KtpCapture } from "@ktp-kit/react";
<KtpCapture base="/ktp-kit/" onResult={r => setKtp(r)} />

Vue

npm install @ktp-kit/vue

<KtpCapture base="/ktp-kit/" @result="r => ktp = r" />

Headless (UI sendiri)

import { useKtpCapture } from "@ktp-kit/react";   // sama di @ktp-kit/vue
const { videoRef, state, shoot, retake, readFile } = useKtpCapture({ base: "/ktp-kit/" });

perlu_dicek

Field yang sebaiknya dicek ulang oleh user, lengkap dengan kode alasannya. Teks yang tampil ke user Anda yang tentukan.

KodeArtinya
nik_mismatchIsi kartu beda dengan yang ada di NIK (tanggal lahir, jenis kelamin). Salah satunya salah baca.
from_nikTulisan di kartu tidak terbaca, jadi nilainya diambil dari NIK. Biasanya benar, tapi bukan hasil baca kartu.

Contoh form

Pasang input untuk field yang Anda butuhkan saja. Selama name input sama dengan nama field di result, potongan kode ini sudah cukup untuk mengisinya. Field lain diabaikan.

<ktp-capture base="/ktp-kit/"></ktp-capture>
<form id="daftar">
  <input name="nik"> <input name="nama"> <input name="tanggal_lahir">
  <button>Daftar</button>
</form>
<script>
  let ktp = null;
  const form = document.getElementById("daftar");
  document.querySelector("ktp-capture").addEventListener("ktp-result", e => {
    ktp = e.detail;
    for (const [k, v] of Object.entries(ktp)) if (form.elements[k]) form.elements[k].value = v ?? "";
  });
</script>

Kalau user tidak boleh mengubah suatu field, tambahkan readonly. Untuk menandai field yang perlu dicek:

for (const [field, alasan] of Object.entries(ktp.perlu_dicek))
  form.elements[field]?.classList.add("perlu-dicek");

React

const [form, setForm] = useState({ nik: "", nama: "" });
<KtpCapture base="/ktp-kit/" onResult={r => setForm({ nik: r.nik ?? "", nama: r.nama ?? "" })} />
<input value={form.nik} onChange={e => setForm({ ...form, nik: e.target.value })} />

Kirim ke server

Submit form seperti biasa. Foto KTP ikut dikirim hanya kalau memang perlu disimpan.

form.addEventListener("submit", async e => {
  e.preventDefault();
  const data = new FormData(form);
  data.append("ktp", ktp.card, "ktp.jpg");   // opsional
  await fetch("/daftar", { method: "POST", body: data });
});

Di server, perlakukan data ini sebagai input user biasa, karena user bisa mengedit form. Validasi ulang NIK dengan function yang sama:

import { nikValid, nikConflicts } from "ktp-kit";

app.post("/daftar", upload.single("ktp"), (req, res) => {
  const { nik, tanggal_lahir, jenis_kelamin } = req.body;
  if (!nikValid(nik)) return res.status(400).json({ error: "NIK tidak valid" });
  const beda = nikConflicts({ nik, tanggal_lahir, jenis_kelamin });   // misalnya ["tanggal_lahir"]
  if (beda.length) return res.status(400).json({ error: "Tidak cocok dengan NIK", field: beda });
  // simpan ke database
});

Perlu memastikan NIK benar-benar terdaftar? Itu butuh verifikasi ke data Dukcapil lewat provider resmi. Panggil dari server, dan hanya untuk pendaftaran yang memang membutuhkannya.

Offline

Saat pertama dipakai, ktp-kit menyimpan model di device (Cache API). Setelah itu baca KTP tetap jalan tanpa internet selama halaman terbuka. Supaya halaman juga bisa di-reload tanpa internet, app Anda butuh service worker yang meng-cache halamannya sendiri (HTML, JS, CSS). Contoh singkatnya ada di apps/demo/sw.js.

Privasi

Foto dan data KTP tidak keluar dari device sampai app Anda sendiri yang mengirimnya. Request network dari ktp-kit hanya untuk download modelnya. UU PDP meminta data dikumpulkan seperlunya, jadi kirim field yang dibutuhkan saja, dan tidak usah simpan foto KTP kalau tidak wajib.

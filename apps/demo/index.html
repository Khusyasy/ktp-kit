Cara kerja

Empat langkah, semuanya di perangkat pengguna. Model diunduh sekali (sekitar 27 MB), lalu disimpan untuk dipakai offline.

  1. Temukan kartu

    Model sudut kartu memandu kamera: jarak, kemiringan, blur, dan pantulan cahaya.

  2. Luruskan

    Kartu dipotong dan diluruskan ke ukuran KTP, 85,6 × 54 mm.

  3. Baca tiap baris

    Baris teks ditemukan, lalu dibaca oleh model yang dilatih khusus untuk huruf KTP.

  4. Isi 16 kolom

    Nilai dicocokkan dengan tata letak KTP, daftar resmi, dan kode wilayah Kemendagri. Yang tidak cocok dengan NIK ditandai.

Dibanding API OCR KTP

API OCR mengirim foto KTP ke server pihak ketiga. ktp-kit membaca di perangkat pengguna.
